jQuery Selectors Used

#changeText
Selects the button with the ID "changeText" and changes its text when clicked.
#doubleClick
Selects the paragraph with the ID "doubleClick" and changes the text color when double-clicked.
#hoverText
Selects the paragraph with the ID "hoverText" and changes its background color when hovered over.
